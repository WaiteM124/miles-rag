# Posting Manual Journals

Manual journals in this ERP are posted from the Journals workspace. A journal must balance: total debits must equal total credits before it can be posted.

To post a manual journal:
1. Open Journals and select New Journal.
2. Enter the journal date and a narrative of at least 20 characters.
3. Add journal lines. Each line requires an account code, a description, and either a debit or credit amount.
4. Select Validate. The system checks that the journal balances and that all account codes are active.
5. Select Post. Posted journals cannot be edited; corrections require a reversing journal.

Reversing journals: create a new journal, select the Reverse option, and reference the original journal number. The reversal posts on the date you specify.
